# مدرسة سراج الدارين | Siraj al-Darayn School

Static website for Siraj al-Darayn Primary & Secondary School.

## Features
- Bilingual (Arabic / English) with RTL/LTR support
- Dark / light theme toggle
- Animated hero, scroll reveals, and photo carousel
- Fully responsive

## Files
- `index.html` - page markup
- `style.css` - styles and themes
- `app.js` - animations, carousel, language/theme switching
- `assets/` - images and logo

## Run locally
```bash
python3 -m http.server 8000
```
Then open http://localhost:8000
